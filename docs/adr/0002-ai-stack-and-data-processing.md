# ADR-002: Выбор стека и подход к обработке данных AI

**Статус:** Принято  
**Контекст:**  
Проект "Поток" является пилотом методологии Kon-Matrix. Нам требовалось создать систему, которая демонстрирует семантический поиск, этические аксиомы и локальную работу, оставаясь при этом прозрачной и контролируемой.

**Решение:**  
1. **Бэкенд:** FastAPI (Python). Выбор обусловлен нативной поддержкой асинхронности, типизацией (Pydantic) и богатой экосистемой для ML/AI (sentence-transformers, chromadb).
2. **Фронтенд:** Flutter. Обеспечивает кроссплатформенность (Linux, Android, iOS) из единой кодовой базы.
3. **Обработка данных:** 
   - Эмбеддинги генерируются локально (CPU mode) для гарантии приватности.
   - Векторное хранилище (ChromaDB) работает локально.
   - Персональные данные пользователей не передаются во внешние LLM API без явного согласия (принцип PUR).

**Последствия:**  
- Система может работать автономно (offline-first).
- Требуется мониторинг производительности при генерации эмбеддингов на CPU.
- Архитектура готова к подключению локальных LLM (Ollama) в будущем.
