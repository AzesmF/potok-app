# Поток — Твои мысли, организованные ИИ

**Гибридный ежедневник нового поколения с ИИ-обработкой**

## О проекте

Поток — это приложение-дневник, которое объединяет простоту бумажной записи с мощью искусственного интеллекта. ИИ не просто хранит записи — он анализирует, структурирует и помогает принимать решения в духе Поля Со-Творения.

### Ключевые возможности (MVP)
- 📝 **Текстовый ввод** — быстрые записи мыслей и задач
- 🤖 **ИИ-обработка** — структурирование, приоритизация, поиск связей
- 💬 **Отвечающий дневник** — эмпатичные ответы и вопросы для рефлексии
- 🔄 **Кроссплатформенность** — мобильные устройства + десктоп

### Будущие возможности
- ✍️ Рукописный ввод с распознаванием почерка (99%+ точность)
- 🎯 Режим фокуса и аналитика продуктивности
- 🔗 Скрытые связи между задачами (векторный поиск)

## Архитектура

Проект построен как Monorepo со следующей структурой:

    potok-app/
    ├── backend/          # FastAPI (Python 3.11)
    │   ├── app/
    │   │   ├── api/v1/   # REST API endpoints
    │   │   ├── core/     # Конфигурация и утилиты
    │   │   ├── services/ # Бизнес-логика и LLM-интеграция
    │   │   └── main.py   # Точка входа FastAPI
    │   └── requirements.txt
    ├── frontend/         # Flutter (мобильные + десктоп)
    │   └── lib/
    ├── docs/
    │   └── adr/          # Architecture Decision Records
    ├── tools/            # Скрипты KON-MATRIX
    └── .github/workflows/ # CI/CD пайплайны

## Технологический стек

- **Backend**: Python 3.11, FastAPI, Pydantic
- **Frontend**: Flutter (iOS, Android, Windows, macOS, Linux)
- **CI/CD**: GitHub Actions
- **Методология**: KON-MATRIX (L1/L2)

## Методология разработки

Этот проект является **первым внешним пилотом методологии KON-MATRIX** — системы оценки зрелости процессов разработки на основе 4 принципов:

1. **Целостность (INT)** — верификация структуры и подписанных коммитов
2. **Чистота (PUR)** — мониторинг зависимостей и документирование
3. **Становление (EVO)** — архив архитектурных решений (ADR)
4. **Прозрачность (TRA)** — структурированные логи и метрики

### Текущий уровень зрелости
- ✅ **L1 (Базовый)**: Автоматизирован
- 🔄 **L2 (Продвинутый)**: В процессе реализации
- ⏳ **L3 (Целевой)**: Запланирован

Подробнее: [KON-Matrix Repository](https://github.com/AzesmF/Kon-Matrix)

## Быстрый старт

### Backend

    cd backend
    python -m venv venv
    source venv/bin/activate  # Linux/macOS
    pip install -r requirements.txt
    uvicorn app.main:app --reload

API будет доступен по адресу: http://localhost:8000
Документация Swagger: http://localhost:8000/docs

### Проверка KON-MATRIX L1

    python3 tools/scanner-l1.py
